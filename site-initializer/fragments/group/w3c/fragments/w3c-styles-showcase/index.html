Typography

The W3C design system uses Noto Sans (with Trebuchet MS as a fallback). Headings follow a "planet" scale.

.txt-venus / h1
Welcome to the W3C design system
.txt-earth / h2
A worldwide community for the Web
.txt-mars / h3
Standards for an open Web
.txt-jupiter / h4
Working groups and community
.txt-saturn / h5
Specifications and reports
.lead
This design system documents the styles, components and templates available to use on your website.
body
The goal of the Web is to serve humanity. We build it now so that those who come to it later will be able to create things that we cannot ourselves imagine.
.txt-eris / 14px
Used for footer text, captions, language nav and meta information.
